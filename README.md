A program that sends exactly one letter — A for coffee — for make.fun's "One Letter: Coffee or Tea" bounty. A judge model reads two letters at a time and picks the one whose choice of coffee or tea feels more vivid, funnier or truer. Coffee is the pick: darker, bitter, the morning jolt — more vivid, funnier, and truer than tea's soft calm.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py
```
